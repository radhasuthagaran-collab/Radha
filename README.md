# PLAYRUSH

A no-build, responsive browser game starter you can publish with GitHub Pages. Everything runs from a single `index.html`; no software installation, API keys, or coding setup is required.

## Publish it with GitHub Pages

1. Open this repository on GitHub and select **Settings**.
2. In the sidebar, choose **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait a minute or two; GitHub Pages will show your website URL in the Pages settings.

## What's included

- A responsive PLAYRUSH home page and game discovery with search and category filters.
- 150 uniquely named game concepts spanning 10 genres. Each has a themed card and description.
- Seven playable original obstacle-course games, each with a distinct visual palette, three stages, checkpoints, hazards, keyboard/touch controls, and finish rewards.
- Avatar customization, a coin shop, daily reward, achievements, profile statistics, favorites, recent games, and a local friends list.
- A tile-based game creator that can save, reload, and play your own simple platform map.
- Progress saved in the browser's local storage.

## Important starter-version notes

This is a static, single-player prototype. The 150 worlds are original catalog concepts; the seven obbies and player-built maps are the playable platformer experiences in this first version. Avatars, coins, friends, and creations are stored only in the current browser on the current device. There is no account service, live multiplayer, online chat, moderation backend, cross-device sync, or cloud publishing. Do not enter sensitive personal information. A real public multiplayer platform would need secure server-side accounts, moderation, persistence, and game hosting.

To update the site later, edit `index.html` in GitHub and commit the change. GitHub Pages will publish it automatically.
